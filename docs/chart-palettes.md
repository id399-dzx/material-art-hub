# 科研图表配色与对照

统一入口为 `src/lib/data-processing/chart-palettes.ts`。本轮参考 [plot-is-all-you-need](https://github.com/liouhai/plot-is-all-you-need) 自绘 Matplotlib 示例中的蓝橙、蓝青玫红、紫橙等颜色，并参考同一份数据比较方案的工作流。MIT 许可与说明保留在 `public/plot-style-references/`。网页图式、实际预览与交互由本项目独立实现。

## 分类配色

- 期刊蓝橙：蓝橙、红绿与紫金，适合多系列曲线。
- 蓝青玫红：亮蓝与玫红交替，适合散点与分布。
- 鲜绿暖橙：鲜绿暖橙搭配蓝紫，适合柱图和类别组成。
- 紫橙对比：紫橙与蓝红，适合箱线和多面板。
- 清新柱面：填充图的粉彩备选，保持边界清晰。
- 色觉友好：Okabe–Ito 配色，常见折线和散点结合线型/点形。
- 黑白印刷：灰阶，常见折线结合线型和点形。

新的模板按图形类型选择初始主题，完整的 182 张目录预览使用同一初始化配置。数据处理主界面、L1502 与论文参考图的分类配色卡片显示当前数据的真实图式。打开“配色对照”后，在固定预览区查看当前方案与三种可选择方案，应用后返回图表。

## 独立数值色阶

`scalarPalette` 是可选的独立字段：紫蓝青黄（Viridis）、清晰蓝阶、蓝粉对照、蓝红对照、暖橙强度、灰阶强度。分类颜色改变不会覆盖显式选择的数值色阶。纯热图和曲面提供六种当前数据色阶预览，不展示无作用的分类色卡。

数值范围、数据绑定和计算方式保持绘图引擎原逻辑。相关/正负热图默认蓝红，以原有对称范围映射；非负频数使用顺序色阶。单向和双向色阶由用户根据数值含义选择，色阶切换不改变数据值或计算结果。

## 保存与渲染

旧快照没有 `scalarPalette` 时继续采用原有的主题/自定义色阶；更改分类颜色时将旧数值渐变冻结为可保存的 `scalarColors`，L1502 中已保存的自定义颜色数组与旧淡彩色数组不会自动重写；用户选择新方案后才替换。论文参考图保留“原图配色”选项，MATLAB 源码保持原样。

缩略图按完整画布生成 SVG，不裁剪坐标轴、标注和图例。编辑预览采用异步逐张渲染与输入防抖，参数或闭包中的数据变更使缩略图重新生成，实例用后释放。

通过 `node --experimental-strip-types scripts/generate-drawing-previews.mjs --check` 重新生成完整目录，并检查非有限坐标、位图与文字越界。

## 指定类别恢复初始配色

按用户要求，热图（9 张）、三维图（36 张）、等高线与场图（11 张）共 56 张模板恢复首次统一配色前 `f427311` 的默认颜色；其余 126 张继续使用当前优化配色。`original-chart-colors.ts` 同时供编辑器和目录 SVG 使用，保留二维场图、三维数值渐变、普通热图及论文来源热图各自的原始色阶。

这些模板提供“初始色阶”预览卡；切回初始数值渐变保留用户数据、坐标、标注与分类颜色。L1502 的“初始配色”卡可恢复系列颜色和对应色阶。旧编辑快照按保存内容恢复，原 MATLAB 源码不变。二维常量数据恢复原青色，手动选择其他色阶仍覆盖该颜色。
