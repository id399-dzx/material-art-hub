# 科研图表配色

统一入口为 `src/lib/data-processing/chart-palettes.ts`。参考用户提供的 AddcolorPlus 色卡重新组合颜色，不执行或分发其 MATLAB P-code，也不声称复现全部 342 个色号。

## 可选方案

- 期刊经典（默认）：蓝、珊瑚、青绿等多组对比色。
- 海盐蓝绿：蓝青与冷绿。
- 自然大地：森林绿、陶土与麦金。
- 莓果暮色：紫莓与灰蓝。
- 柔和粉彩：淡彩柱图、面积填充及演示。
- 色觉友好：保留 Okabe–Ito 颜色。
- 黑白印刷：灰阶及引擎已有的线型、纹理区分。

每套方案分别定义 `colors`（系列分类色）、`sequential`（有序数值渐变）和 `diverging`（以零为中心的正负数值渐变）。数值范围、数据绑定和计算方式保持原逻辑；热图、密度、曲面、颜色数值列使用有序色阶。已有正负热图继续使用以零为中心的范围。

## 使用与兼容

数据处理主界面、论文模板编辑器和模板缩略图共享默认主题。数据处理主界面主题选择后立即更新主曲线及对比曲线，单曲线仍可自定义颜色；模板编辑器实时更新。

旧保存的自定义色数组不会自动改写，选择新方案时才替换。旧版模板快照继续接受原有主题 ID，新主题也可保存到组图快照。原始论文图式仍提供“原图配色”选项。MATLAB 代码保持原始文件。

预览资源通过 `node scripts/generate-drawing-previews.mjs --check` 重新生成并检查完整画布及文字边界。
