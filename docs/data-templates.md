# 数据模板

入口：`/data-processing#data-templates`。18 类模板按比较、组成、曲线、矩阵、空间、示意分组，支持关键词搜索。切换工作台导航时保留文件、列绑定和样式；刷新页面后恢复示例。

## 模板目录

| 分类 | 模板 | 输入 |
| --- | --- | --- |
| 比较 | 分组柱状、横向比较、均值与误差条、多指标雷达、多指标分面 | 类别或指标名称 + 数值列；误差条可输入重复实验或均值/误差；分面可切换数值 X 的参数扫描折线 |
| 组成 | 堆叠组成、百分比组成 | 类别 + 非负组成数值，使用相同单位 |
| 曲线 | 多组折线、时间趋势与累计、双轴参数曲线 | 数值 X 或时间标签 + Y；双轴选择两列 Y |
| 矩阵 | 矩阵热图 | 首列行名称，其余列为矩阵数值 |
| 空间 | 多组散点、三维球面与向量、三维曲面与流形、二维流形与轨迹、关系网络 | 数值坐标；网络使用起点、终点、可选非负权重 |
| 示意 | 概念曲线与差异标注、流程与框架 | 数值 X + 至少两条曲线；流程使用起始步骤和后续步骤 |

## 操作

1. 选择模板，查看数据格式说明和示例。
2. 使用演示数据试用，或导入不超过 10 MB 的 CSV、XLS、XLSX。Excel 可切换工作表；无表头数据取消“首行为列名”。
3. 绑定数据列。三维模板分别绑定 X、Y、Z；网络与流程绑定起点和终点。
4. 调整标题、轴名称、字体、配色、尺寸和网格。趋势图可开启累计；概念图可设置参考位置；三维图可调整方位角与仰角。
5. 导出 SVG 或三倍尺寸 PNG；也可下载各模板的示例 CSV。

## 数据规则

- 空白或非数值不当作零。选中数据列不完整的行整体跳过并提示原始行号。
- 折线、参数扫描和轨迹保留原始点顺序，不自动排序、平滑、插值或填补。
- 柱状图每行对应一个类别，重复类别需要用户先汇总。
- 重复实验至少两列；SD 为样本标准差（分母 n−1），SEM 为 SD / √n。
- 汇总误差必须为非负数；填写的误差值不会转换。识别到 SEM / 标准误列时默认 SEM，否则默认 SD，用户应按实验记录确认。
- 百分比组成按每行总量转换为 100%，总量必须大于零；原始数据保留不变。
- 雷达保留原始数值、零基线，各指标自动计算并标示轴上限。不同单位的指标应谨慎比较。
- 热图使用全部选中数值的统一色阶。双轴与分面采用独立坐标范围，不通过图形高度直接比较不同轴的数值。
- 累计按输入顺序逐行求和；用户需先整理时间顺序。
- 三维模板是等比例正交投影，可导出当前视角；球面半径 1 仅供参考，不自动单位化向量。曲面仅连接完整四角，不填补孔洞，拒绝重复 X/Y 坐标。
- 三维最多 2500 个顶点，曲面最多 10000 个可能网格位置；分面最多 6 个指标；关系图最多 100 个节点、500 条连接。
- 网络仅显示输入的连接，布局不表示节点距离。无环流程从左到右分层，有环关系使用圆形布局。
- 内置数据是自编的布局演示，画布与导出标题均标注示例。模板不进行降维、模型推断、概率拟合或统计显著性计算。
- 文件读取、数据计算及图像导出均在浏览器完成。

## 来源与覆盖核对

参考 [figures4papers](https://github.com/ChenLiu-1996/figures4papers) 的通用科研图表分类；核对版本 `f0bb7559abe90f5e1828797126d4d133c1bd47d7`。

- `figure_Brainteaser`：组成堆叠及类别/子类别、重写、自校正比较 → 组成图、比较图、分面。
- `figure_CellSpliceNet`、`figure_ImmunoStruct`：消融比较、方法比较、横向柱和误差 → 比较与误差条。
- `figure_Cflows`：消融、基因调控与轨迹比较、Swiss roll 热图和散点连接 → 比较、分面、热图、散点、轨迹和网络。
- `figure_Dispersion`：球面、向量及空间概念展示 → 球面与向量、散点。
- `figure_RNAGenScape`：比较、热图、曲面、带孔曲面与参数扫描 → 比较、热图、曲面和参数折线分面。
- `figure_VIGIL`：雷达、双轴消融、概念分布/嵌入与训练曲线 → 雷达、双轴、概念、散点和折线。
- `figure_ophthal_review`：组成热图、年度/累计趋势 → 热图和趋势。
- README 中手工复合图与方法框架 → 可输入步骤连接的流程框架。任意手绘插图与具体论文排版仍需图表画布编辑。

覆盖的是可复用图表类型，未逐张复刻论文专用图。未复制源项目代码、图片、配色文件、实验数据或文档。图表选项、缩略图和示例表格独立实现，使用项目已有的 ECharts 和 SheetJS。

- `src/lib/data-processing/template-chart.ts`：基础图表。
- `src/lib/data-processing/template-chart-extended.ts`：扩展图表及连接布局。
- `src/lib/data-processing/template-chart-spatial.ts`：正交投影与完整网格连接。

验证：`node --experimental-strip-types --test src/lib/data-processing/templates.test.mjs`。覆盖缺失值、真实行号、SD / SEM、类别校验、误差条定位、CSV 转义、全部 18 类 SVG 渲染、百分比/累计/独立轴、参数面板、曲面孔洞和显式连接。

生成缩略图：`node --experimental-strip-types scripts/generate-template-previews.mjs`。
