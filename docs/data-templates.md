# 通用数据绘图（已合并至论文图例模板）

入口：`/data-processing#paper-figures`；旧链接 `#data-templates` 仍可使用。[论文图例模板单图库](paper-figure-templates.md) 当前包含 **43 个数据模板、10 个分类**：17 个通用模板、18 个论文图式代表，以及新增 8 个电化学测试模板。原有结构去重修正，补回 12 个独立论文图式，两种小提琴全部保留；机制插图已删除。本文说明图表的数据规则。切换工作台导航时保留文件、列绑定和样式；刷新页面后恢复示例。

## 操作

1. 目录页仅展示模板、分类与搜索。点击任意模板卡片，弹出编辑工作台；已用模板显示「继续编辑」。
2. 在弹窗内使用演示数据试用，或导入不超过 10 MB 的 CSV、XLS、XLSX。Excel 可切换工作表；无表头数据取消“首行为列名”。需要时展开「数据检查与绘图建议」，纠正字段类型、选择分组与表达目的，再应用建议。
3. 绑定数据列。三维模板分别绑定 X、Y、Z；网络与流程绑定起点和终点。电化学模板根据表头给出建议，所有字段仍可手动修改；导入后轴名使用实际绑定表头，不自动换算单位。Nyquist 需要确认虚部列已是 −Im(Z) 还是原始 Im(Z)；循环性能可不显示库仑效率；Bode 分别绑定模值与相位。
4. 调整标题、轴名称、字体、配色、尺寸和网格。趋势图可开启累计；概念图可设置参考位置；组成图可开关纹理；三维图可调整方位角与仰角，球面与向量可开关单位参考球。
5. 预览可适应窗口或显示原始尺寸；导出设置选择 85 / 180 mm 或自定义宽度（40–300 mm），保持画布比例。PNG 可选 150 / 300 / 600 DPI，并写入真实 DPI 元数据。可导出 SVG、灰度版本，或通过浏览器打印存为 PDF；也可下载示例 CSV。每次导出重新检查矢量文字边界、最小字号和重叠。
6. 点击关闭、返回模板列表、弹窗外背景或按 Esc 返回目录；当前页面内保留数据和样式，刷新前请导出。手机上编辑工作台全屏显示。读取和导出期间暂时禁用关闭操作。

## 数据规则

- 空白或非数值不当作零。选中数据列不完整的行整体跳过并提示原始行号。
- 折线、参数扫描和轨迹保留原始点顺序，不自动排序、平滑、插值或填补。
- 电化学曲线也保留采集顺序，CV 的重复电位与往返扫描不合并。Nyquist 虚部仅按明确选择保持原值或乘以 −1，不取绝对值；实部和虚部须使用相同单位，两轴保持相同像素 / 数值比例。Bode 的原始频率和阻抗模值必须大于零；遇到零或负数会阻止绘图并提示，不自动删行或改成正数。相位保留符号，使用右侧线性轴。
- 电化学模板不自动归一化面积 / 质量、不换算参比电极、不做 iR 校正、不计算库仑效率或容量保持率、不拟合等效电路或 Tafel 参数。单位、参比和实验条件由用户在轴名、列名及图注中明确，详细要求见[电化学专栏](electrochemical-templates.md)。
- 多组折线使用数值 X 的实际间距；时间趋势使用输入的分类标签。堆叠面积默认绘制各组输入值的堆叠总量，不再额外逐行累计。
- 箱线 / 小提琴输入类别和单列真实样本的长表。保留零与重复值。n<3 不绘箱体；小提琴 n<5 或常量组不拟合密度。直方图统计单列数值，末区间包含右端点；不按表格行均值生成伪样本。
- 字段检查显示缺失 / 无效比例、范围、均值、中位数、样本 SD、分组有效 n、IQR 提示和逐对 Pearson 相关。不删除异常值，不自动填补；数字 ID 可手动改为文本。
- 柱状图每行对应一个类别，重复类别需要用户先汇总。
- 重复实验至少两列；SD 为样本标准差（分母 n−1），SEM 为 SD / √n。
- 汇总误差必须为非负数；填写的误差值不会转换。识别到 SEM / 标准误列时默认 SEM，否则默认 SD，用户应按实验记录确认。
- 百分比组成按每行总量转换为 100%，总量必须大于零；原始数据保留不变。
- 雷达保留原始数值、零基线，各指标自动计算并标示轴上限。不同单位的指标应谨慎比较。
- 热图使用全部选中数值的统一色阶。双轴与分面采用独立坐标范围，不通过图形高度直接比较不同轴的数值。
- 累计按输入顺序逐行求和；用户需先整理时间顺序。
- 三维模板是等比例正交投影，可导出当前视角；球面半径 1 仅供参考，不自动单位化向量。曲面仅连接完整四角，不填补孔洞，拒绝重复 X/Y 坐标。
- 三维最多 2500 个顶点，曲面最多 10000 个可能网格位置；分面最多 6 个指标；关系图最多 100 个节点、500 条连接。
- 网络仅显示输入的连接，布局不表示节点距离。无环流程从左到右分层，有环关系使用圆形布局。
- 内置数据是自编的布局演示，画布与导出标题均标注示例。模板不进行降维、模型推断或统计显著性计算；小提琴的核密度仅用于描述现有样本。新数据图不会复制源论文的 P 值或结论。
- 文件读取、数据计算及图像导出均在浏览器完成。

## 来源与覆盖核对

参考 [figures4papers](https://github.com/ChenLiu-1996/figures4papers) 的通用科研图表分类；核对版本 `f0bb7559abe90f5e1828797126d4d133c1bd47d7`。

- `figure_Brainteaser`：组成堆叠及类别/子类别、重写、自校正比较 → 组成图、比较图、分面。
- `figure_CellSpliceNet`、`figure_ImmunoStruct`：消融比较、方法比较、横向柱和误差 → 比较与误差条。
- `figure_Cflows`：消融、基因调控与轨迹比较、Swiss roll 热图和散点连接 → 比较、分面、热图、散点、轨迹和网络。
- `figure_Dispersion`：球面、向量及空间概念展示 → 球面与向量、散点。
- `figure_RNAGenScape`：比较、热图、曲面、带孔曲面与参数扫描 → 比较、热图、曲面和参数折线分面。
- `figure_VIGIL`：雷达、双轴消融、概念分布/嵌入与训练曲线 → 雷达、双轴、概念、散点和折线。
- `figure_ophthal_review`：组成热图、年度/累计趋势 → 热图和趋势。
- README 中手工复合图与方法框架 → 可输入步骤连接的流程框架。纯机制 / 结构图片不再作为数据模板展示。

覆盖的是可复用数据图结构；原论文的同类区域现合并到代表模板，而不是按来源面板重复列出。通用绘图代码与示例表格独立实现；论文代表图式参考来源结构和配色并保留署名。新增 8 个电化学目的模板和演示数据独立编写，虽复用折线或双轴引擎，但具有各自的坐标、字段建议与输入校验。当前全部 **31 张缩略图**由本地 SVG 渲染器生成完整画布，不再裁剪源图片。原始论文图片仅作为溯源资料保留，遵循对应署名和许可证；该参考素材许可不会新增为电化学演示模板的限制。
