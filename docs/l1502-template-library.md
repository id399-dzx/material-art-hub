# L1502 数据图式库

完整收录本地 `Matlab论文插图绘制模板` 第 1–139 期的图式身份，保留原名称、期号和文件夹引用。与已有 43 个图式合并，共 182 个数据模板。分类沿用网站中央目录，新增极坐标、等高线与场、文本、多图布局分类。

## 使用入口

`/data-processing?templates=l1502#paper-figures` 打开 L1502 来源筛选。页面展示分类和模板卡片；点击后打开单图编辑弹窗，导入 CSV/Excel、绑定字段、调整样式并导出。下载“数据结构”可以获取当前图式的示例 CSV。

## 数据与绘图

- 图式与参数：`l1502-catalog.ts`、`l1502-spec.ts`。
- 示例数据：`l1502-demo.ts`，确定性独立生成，明确标记为示例。
- 字段建议、数值与结构验证：`l1502-data.ts`。
- 二维、极坐标、网络、文本与多面板：`l1502-render-2d.ts`。
- 三维：`l1502-render-spatial.ts`，SVG 投影，可调整方位和俯仰。曲面使用实际网格，散点曲面按 XY 三角剖分，等值面由 XYZ 标量场计算。
- 完整预览：`scripts/generate-drawing-previews.mjs --check`。使用编辑器相同的数据绑定与渲染器，检查文字边界，不裁剪来源图片。

网页图式独立实现；源文件夹用于识别参考图式，配色使用网站定义的方案。根据用户要求，详情页另外提供对应原始 MATLAB `.m` 源码供查看、复制与下载，保留源码中的作者和出处注释。网页不执行 MATLAB 程序，不分发原 MAT 数据、图片或加密 P-code。

## MATLAB 源码

L1502 的 139 期均有对应源码，共 143 份 `.m` 文件。第 49、76、85、87 期分别有两份，可在详情页选择脚本；第 85、87 期含箭头配色辅助函数。源码按期号匹配，独立于网页绘图引擎，切换源码与图表编辑不会丢失已导入的数据和样式。

代码内容在打开源码页签后加载，一键复制当前完整脚本；复制失败时提供手动选择。源码中的 `load`、外部配色函数等依赖会显示在详情中，用户须在 MATLAB 环境中自行准备相应文件。浏览器演示数据与原 MATLAB 测量数据并不相同。

## 数值约定

区间图使用输入的上下界，不把演示区间宣称为计算出的置信区间。误差值需要已计算的非负幅度。箱线图输入原始样本；缺口采用近似中位数区间，并在图中解释。向量起点和分量分别绑定。极坐标输入角度为弧度，内部转换为角度显示。对数轴拒绝非正坐标。缺失观测提示并略过，网格缺失不填零。函数类模板接收采样数据，不执行任意公式代码。

## 导出与组图

使用现有论文导出模块生成物理尺寸 SVG、带 DPI 元数据的 PNG，以及打印 PDF。最终字号以 pt 设置，按输出毫米宽度换算。加入论文组图时保存原始工作表、字段绑定、样式、轴设置和导出规格；编辑原图可恢复，工程和浏览器草稿继续使用现有机制。新快照 `kind: l1502` 独立验证，避免旧引擎误读。

## 管理

管理员可以调整模板展示名称、分类、描述、数据要求、标签、指南和默认轴名，或隐藏卡片。引擎配置、示例数据和渲染源不是可写的管理字段。
