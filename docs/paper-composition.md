# 论文组图 · 第一阶段

入口：`/data-processing#paper-composition`。它是数据处理内部的独立工作区。

## 用户流程

1. 在模板编辑弹窗或主图表画布中完成单图，点击“加入论文组图”。主画布修改参数后须先点击“更新图表”；加入的是实际呈现的图形。
2. 在组图工作区添加 PNG、JPEG 或静态 SVG 图片，可多选。每张图片上限 20 MB。
3. 选择网格、单行、单列、上方主图或左侧主图布局。自动布局默认让高度随内容调整；选择画布比例或手填高度后切换为固定高度。
4. 点击子图进行选择，拖动移动或缩放，方向键微调。可编辑位置、尺寸、编号、字体与图注，修改布局后重新自动排版。
5. 网站生成的图支持“编辑原图”。恢复完整数据与编辑配置，更新相同源图时保留子图位置、尺寸、图注与顺序。
6. 按最终物理尺寸导出 SVG、带 DPI 元数据的 PNG，或打印存为 PDF。

编号、图注占用独立空间。默认完整显示原图并保持其比例；选择框与操作控件不会进入导出文件。固定画布过小会提示调整高度或留白。

## 草稿与工程

- IndexedDB 数据库 `fesilent-figure-composition` 保存当前浏览器的草稿。编辑后自动保存，也可手动保存；失败会明确提示下载工程备份。
- `.figure.json` 工程包含原始图片、原始数据与编辑参数、子图布局、导出规格和高度模式，可下载后在另一浏览器重新打开。工程上限 64 MB，最多 100 张素材及 100 张子图。
- 打开工程或新建时提示备份；替换、删除、移动、排序等操作支持撤销和重做。撤销历史保留当前页面最近 30 次操作，不随刷新保存。
- 草稿当前保存在本机浏览器，没有云端同步或公开分享功能。

## 图形与来源

- 数据图保持 SVG 路径和文字，上传位图保持原有分辨率。增大导出 DPI 不会增加原图细节。
- SVG 支持常见 Matplotlib / Illustrator 静态样式、字体缩写、渐变、裁剪与内部引用；组合时隔离图内 ID。脚本、事件、外部资源和动态样式不接受。
- 保留模板来源说明、示例数据标记和统计图注。输出检查会提示示例数据、图形越界、子图重叠、文字大小和位图有效分辨率等问题。
- 图表源档保存数据与编辑参数，重新调用现有绘图引擎，不序列化包含函数的 ECharts option。

本功能使用独立的 TypeScript/SVG 实现。没有复制或执行 SlideSCI 的源码。
