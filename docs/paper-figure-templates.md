## 复合模板的编辑方式

1. 选择具体图例，在图中点击目标面板，或使用绘图区下拉菜单。
2. 下载「此面板 CSV」或「整图 CSV」，替换示例数值后导入 CSV / XLS / XLSX（10 MB 内）。整图长表使用 `panel` 区分面板，一次导入可以同时更新多个面板。
3. 选择「文字标注」，搜索或点击原图文字，修改标题、指标、方法名、统计值、说明和结论。竖向轴标题保留竖向排版。文字来自 OCR，公式、上下标和识别结果需要人工核对。
4. 选择「插图」，上传自己的 PNG / JPEG / WebP（10 MB 内），在既定模块区域等比例放置。
5. 用「原图对照」切换检查，按需放大到 300%；可撤销最近一次操作、恢复单个区域或整图。
6. 导出内嵌底图的 SVG，或 2400 像素宽 PNG。保存 `.paper-figure.json` 工程，之后选中同一图例并打开工程继续编辑。

切换导航或图例会保留本次页面中的编辑；刷新页面不会自动恢复，请先保存工程。所有数据读取与导出在浏览器完成，不调用 AI，不上传实验数据到服务器。

**原图底板和复杂插图仍是位图；替换的图表、文字为 SVG 矢量层。** 这不是整张原图的完全可编辑矢量重建。蛋白结构、手绘网络和机制框架提供模块图片替换，内部路径不能逐点编辑。未替换面板仍含原作者示例数据；原图 P 值、公式、结论和说明不会按新数据自动重算，必须逐项核对。页面和导出附有此说明。

## 表格规则

```csv
panel,series,x,y,z,error
auroc,value,Prime-2.1,0.73,,0.02
```

- `panel`：目录中的面板 ID。省略该列时导入当前面板；存在该列时每行必须指定有效 ID。图片模块不能用数值表替换。
- `series` 和类别型 `x`：沿用下载示例中的数据键，视觉名称另在文字编辑中修改。未知键直接报错。
- 数值型 `x` / `y` 为真实坐标；热图 `z` 为格点值，空间示意 `z` 为第三维坐标。`error` 是用户提供的非负误差，不重算、不转换 SD / SEM。
- 空白、非数值和负误差导致该行整体跳过，提示原始行号；不补零或平均填补。
- 每面板最多 6000 行。组成、面积、雷达和矩阵禁止重复坐标 / 系列；组成比例逐 X 合计为 1。累计面积输入已经累计的数据，不自动累加。
- 雷达沿用原图十二指标的独立刻度，每个系列必须完整，超出基准范围报错。
- 热图沿用原图色标与坐标范围；越界报错。氨基酸位置为整数。缺少的格点不插值，数值坐标单元边界取相邻坐标中点。
- SFT only 为固定基线，各点 Y 必须相同。折线保留输入顺序；曲线和散点超出固定坐标范围时提示，支持调整 X / Y 显示范围并更新刻度。
- 箱线 / 小提琴每个类别系列至少两个真实样本；箱体 Q1 / Q3、中线中位数、须线取 1.5×IQR 范围内最远观测；小提琴由样本核密度绘制，不计算显著性。
- 球面是参考示意和正交投影，不进行模型训练、降维或单位化。演示数据由本站自行编写，不是论文实验数据。

## 实现与检查

- `src/components/data-processing/PaperFigureStudio.tsx`：17 图目录、导入、标注、图片、原图对照、工程保存恢复与导出。
- `src/lib/data-processing/paper-figures/catalog.ts`：逐图面板位置、配色、坐标与保留结构。
- `references.json`：原图来源、尺寸和文字区域。
- `data.ts`：长表校验与自编演示。
- `render.ts`：位图底板与矢量替换层、图例 / 结论框保留、旋转文字与内嵌导出。
