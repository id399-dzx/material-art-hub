# 论文图例模板 · 精选数据图库

入口：`/data-processing#paper-figures`。原「基础绘图」入口已合并；旧链接 `#data-templates` 仍可访问同一个目录。用户按图形类型选一个模板，在弹窗中上传数据、绑定字段、预览并单独导出。

## 模板构成与去重原则

目录先从 118 个条目按结构去重为 23 个模板，再增加 8 个电化学测试模板；当前共有 **31 个数据模板、10 个分类**：17 个通用模板、6 个论文图式代表和 8 个电化学目的模板。同样的图形结构来自不同论文、使用不同指标或配色时，只保留一个代表；标题改用结构名称，便于判断适合什么数据。**两种小提琴模板全部保留**。28 个机制 / 结构插图及其图片替换编辑功能已删除。

同一大类中的多种结构具有不同用途。例如分组柱状用多个系列直接比较，误差图表达已提供或计算的不确定性；堆叠组成保留绝对总量，百分比组成把每行归一化为 100%；数值 X 折线按真实数值间距绘制，分类时间趋势按标签排列；堆叠面积同时展示每组变化与合计规模。多指标分面的数量随绑定列数变化，不要求配齐原论文的 a–h 面板。

六个论文图式代表来自 ImmunoStruct 的纵向 / 横向误差图与小提琴、Brainteaser 的百分比组成、VIGIL 的多组折线和 ophthal_review 的堆叠面积。它们提供可复用结构与参考配色，无需沿用原论文的指标、类别数或数据范围。

电化学专栏的 8 个模板独立编写，按实验用途提供预设。例如 CV 保留往返电位采集顺序，Nyquist 显式确认虚部符号并保持两轴等比例，Bode 对频率与模值使用对数坐标、对相位使用线性右轴；这些流程不是将不同论文的相同曲线再次列成重复卡片。详细输入与使用规则见[电化学测试专栏](electrochemical-templates.md)。

## 数据图操作

1. 点击模板卡片，打开数据图编辑弹窗。
2. 使用演示数据，或上传 10 MB 以内的 CSV / XLS / XLSX。CSV 支持 UTF-8（有无 BOM 均可）、UTF-16 和 GB18030。Excel 可选择工作表。
3. 绑定自己的类别、X、Y 或矩阵列；无需 `panel` 列。类别名称、系列数、样本量、轴范围由用户数据决定。雷达至少 3 个指标；双轴仍需 2 列 Y；三维仍需 X、Y、Z，这是对应图形的输入要求。
4. 均值与误差模板可以关闭「绘制误差条」，只绘制数值。上传有误差列的数据默认显示误差；普通数值文件默认不推断重复实验，用户可明确选择重复实验列或均值与误差列。
5. 设置标题、轴名称、字号、图例配色或通用配色。组成图可切换纹理，球面与向量可切换单位参考球。预览只呈现当前数据图。
6. 导出 SVG、150 / 300 / 600 DPI PNG，或通过浏览器打印 PDF。物理尺寸、图形检查、灰度导出和数据检查继续可用。

电化学文件导入后按实际表头建议字段和轴名称，所有绑定与轴名可修改，单位不会自动转换。Nyquist 上传后必须确认「虚部列输入约定」再生成；Bode 的非正频率或模值会阻止绘图；循环性能的库仑效率右轴可以关闭。

内置表格是独立编写的演示数据，不是原论文实验结果。数值图重新绘制坐标、图例和数值范围，不沿用原论文的固定刻度、P 值、公式或结论，也不会根据新数据自动计算显著性。缺失值不补零，绘图规则见 [通用数据绘图](data-templates.md)。

## 缩略图与裁剪检查

全部 **31 张缩略图**由当前模板渲染器和演示数据生成完整 SVG，包含适用的坐标、标签、图例、误差条及色条。列表使用完整画布缩放展示，不再依据原论文的绘图区矩形裁切图片。这样避免裁图截掉坐标、图例、色条或部分图形，也让模板卡片与点击后的演示图采用相同结构。

`scripts/generate-drawing-previews.mjs` 为全部保留模板重新生成 SVG，并输出完整画布联系表和文字边界审查记录。`--check` 会对越过画布的文字报错；联系表用于人工检查所有模板的图形与标签。边界检查不能替代科学内容核对，用户编辑后仍需检查自己的长标签、字号与布局。

## 目录与弹窗

目录只有模板展示、类型、来源和搜索。「电化学测试」为首个专栏，也可使用 `/data-processing?templates=electrochem#paper-figures` 直接筛选。点击卡片后弹窗，关闭、返回、背景或 Esc 回到目录；当前页面内保留编辑。手机全屏显示，导入和导出期间暂时禁用关闭。刷新前请导出数据图。

## 来源与实现

参考项目：[ChenLiu-1996/figures4papers](https://github.com/ChenLiu-1996/figures4papers)。论文图式在页面与 SVG 中保留来源署名和修改说明。原始 17 张复合图与来源坐标留作溯源资料，不作为当前模板缩略图或用户数据图底板；原图许可见 `public/paper-figures/LICENSE.txt` 和 `ATTRIBUTION.md`，CC BY-NC 4.0 适用于对应参考素材。

电化学模板和演示值由项目独立编写，不包含外部实验数据或图片，也不因这次新增模板而引入上述论文图片许可限制。方法说明采用仪器厂商的官方资料，链接见[电化学模板文档](electrochemical-templates.md)。

- `drawing-catalog.ts`：精选目录、图式代表、分类与绘图建议入口兼容映射。
- `TemplateStudio.tsx`：模板展示、字段绑定与数据图编辑。
- `template-chart*.ts`：各类数值图结构、样式与 SVG 渲染。
- `scripts/generate-drawing-previews.mjs`：完整 SVG 缩略图、联系表与边界审查。
- `electrochemical-templates.ts` / `electrochemical-mapping.ts` / `electrochemistry.ts`：电化学示例、字段建议与坐标约定检查。
- `public/drawing-previews/`：当前 31 个模板的缩略图与来源说明。
- 复合图和独立机制图片的编辑界面已删除。

生成并检查缩略图：`node --experimental-strip-types scripts/generate-drawing-previews.mjs --check`。

目录与输入验证：`node --experimental-strip-types --test src/lib/data-processing/drawing-catalog.test.mjs src/lib/data-processing/read-workbook.test.mjs`。图表数据规则验证见 [通用绘图规则](data-templates.md)。
