# 论文图例模板 · 单图库

入口：`/data-processing#paper-figures`。原「基础绘图」入口已合并；旧链接 `#data-templates` 仍可访问同一个目录。用户按图形类型选一张模板，在弹窗中上传数据、绑定字段、预览并单独导出。

## 模板构成

- **21 个通用绘图模板**：保留原基础绘图的数据绑定、样本统计、样式和导出能力。
- **69 个论文数据单图**：来自 figures4papers 首页 17 张图例的全部已识别数值绘图区。每个区域单独生成模板，提供裁出的原图风格参考、对应的自编演示表格及配色。
- **28 个独立机制 / 结构插图**：从原图分离出的模块，支持整张图片替换、原图文字修改、标题、图注及工程保存恢复。

共 **118 个模板**。默认按类型分组，也可切换类型、来源或关键词筛选。

数字表示独立模板，不表示互不重复的图形类型；同类图可能来自不同论文区域。通用指标分面模板的面板数量随绑定列数变化，不要求配齐原论文的 a–h 面板。

## 数值单图

1. 点击模板卡片，打开单图编辑弹窗。
2. 使用演示数据，或上传 10 MB 以内的 CSV / XLS / XLSX。CSV 支持 UTF-8（有无 BOM 均可）、UTF-16 和 GB18030。Excel 可选择工作表。
3. 绑定自己的类别、X、Y 或矩阵列；无需 `panel` 列。类别名称、系列数、样本量、轴范围不再受原论文限制。雷达至少 3 个指标；双轴仍需 2 列 Y；三维仍需 X、Y、Z，这是对应图形的输入要求。
4. 柱状与误差模板可以关闭「绘制误差条」，只绘制均值。上传有误差列的数据默认显示误差；普通数值文件默认不推断重复实验，用户可明确选择重复实验列或均值与误差列。
5. 设置标题、轴名称、字号、图例配色或通用配色，预览只呈现当前单图。堆叠组成、面积、曲线填充、横向误差条和空间向量提供相应图形结构。数值图重建坐标与图例，不复制原论文的固定刻度、显著性、公式或结论。
6. 导出 SVG、150 / 300 / 600 DPI PNG，或通过浏览器打印 PDF。物理尺寸、图形检查、灰度导出和数据检查继续可用。

原图预览仅用于风格参考，不以原位图覆盖用户图表。演示数值独立生成，不是原论文实验数据。缺失值不补零，绘图规则见 [通用数据绘图](data-templates.md)。

## 独立插图

机制图、蛋白结构和手绘插图属于图片模板。每个模板只有一张独立底图，无其他面板。可上传 10 MB 以内的 PNG / JPEG / WebP，设置标题和图注。使用原图时，可修改裁图内完整的 OCR 标注；上传自己的图片后不叠加原图标注。OCR 文字与公式需要人工核对。

插图工程为 JSON（version 2，绑定当前单图 ID），支持保存和恢复图片、标题、图注与文字修改。导出 SVG 自包含内嵌图片；图片仍为位图，修改文字为矢量。

## 目录与弹窗

目录只有模板展示、类型、来源和搜索。点击卡片后弹窗，关闭、返回、背景或 Esc 回到目录；当前页面内保留编辑。手机全屏显示，导入和导出期间暂时禁用关闭。数值图刷新前请导出，插图可保存工程。

## 来源与实现

参考项目：[ChenLiu-1996/figures4papers](https://github.com/ChenLiu-1996/figures4papers)。原图和裁图资源保留作者署名、出处、CC BY-NC 4.0 许可与修改说明，见 `public/paper-figures/LICENSE.txt`、`ATTRIBUTION.md` 和 `public/paper-panels/ATTRIBUTION.md`。页面保留来源链接。

- `drawing-catalog.ts`：统一目录、类型映射和独立演示矩阵。
- `TemplateStudio.tsx`：模板展示及数值单图编辑。
- `PaperPanelImageEditor.tsx` / `standalone-image.ts`：独立插图编辑与导出。
- `scripts/generate-paper-panel-previews.mjs`：按记录的区域坐标生成 97 张预览和 28 张插图底板。
- 原始 17 张图的坐标与来源记录保留，用于溯源；复合图编辑界面已删除。

验证：`node --experimental-strip-types --test src/lib/data-processing/drawing-catalog.test.mjs src/lib/data-processing/read-workbook.test.mjs`。覆盖所有区域、69 种单图的示例与 SVG、新类别与不同数据量、插图裁切与文字转义，以及中文 CSV 编码。
