# 网页与两个参考项目的实际差距

核对日期：2026-10-01。以代码和可操作页面核对，不把图表名称相同视为实现等同。

- [figures4papers](https://github.com/ChenLiu-1996/figures4papers)，版本 `f0bb7559abe90f5e1828797126d4d133c1bd47d7`：Python 绘图脚本与具体论文复合图。
- [SciPilot](https://github.com/Haojae/scipilot-figure-skill)，版本 `43098ddb9e6a6d142218540c114f9ed38922fc42`：面向编码助手的绘图 Skill、Python 工具与审核参考，不是即装即用的网页组件。

## 对比与本次修正

| 能力 | 参考项目实际提供 | 本站目前实现与差距 |
| --- | --- | --- |
| 具体论文图例 | figures4papers README 的 17 张复合示例 | 17 张逐图对应，保留原图布局和标注；69 个数值区、28 个插图模块。数据和修改文字为矢量层，复杂机制图仍为原图 / 替换位图。 |
| 原始样本分布 | 原图含箱线、小提琴；SciPilot 强调原始点和样本量 | 本次新增独立箱线、小提琴、直方图，基础绘图从 18 到 21 类。保留原始点、零、重复观测，显示分组有效 n。小样本不强行拟合密度。 |
| 数据剖析 | SciPilot 的类型、缺失、异常、统计与相关检查 | 本次增加浏览器本地检查、字段类型纠正、均值 / 中位数 / n−1 SD / IQR 提示、逐对有效 n 的 Pearson。排除缺失而不补零，不把常量的 NaN 解释为强相关。 |
| 按目的推荐 | SciPilot 依靠助手理解用户论点和参考决策框架 | 本次增加目的 / 分组 / 数值三项选择，建议直接应用当前表格。是可解释的规则建议，不具备对论文论证的 AI 理解。主样品 XY 曲线可送入基础绘图。 |
| 物理尺寸与字号 | SciPilot Matplotlib 按 mm / pt / DPI 出图 | 本次统一三个绘图入口，85 / 180 mm 与自定义 40–300 mm，保持画布比例；基础图字号以 pt 控制。PNG 写入 pHYs DPI。SVG 不裁切改变设定尺寸。原图底板中的字号不能统一重排。 |

| 布局检查 | SciPilot 程序检查 + 助手读取成图、回改 | 本次增加矢量文字越界 / 小于 6pt / 重叠检查，每次导出重查。位图文字、图例遮住曲线、缺字字形和科学结论仍需人工看图；未实现 AI 自动审图闭环。 |

## 对原图保真方式的判断

仅把具体论文图压缩成三类通用模板会产生明显差距，已改为逐张复合模板。当前保留原图的版面、框架、原始标注，并允许替换数据模块与文字；复杂蛋白结构 / 网络等提供整模块图片替换。不能把这种实现称为「原图内部每条路径均可编辑」。如果要达到全矢量编辑，需为每张图逐个重建结构和路径，当前未完成。

未替换数值区仍是原作者数据。新数据不会重算原来的 P 值、公式、结论，检查界面明确列出这些提示。原图 CC BY-NC 4.0 与 SciPilot MIT 分开保留，MIT 不覆盖论文图片。

## 验证记录

- 35 项数据和 SVG 渲染测试：覆盖 21 类基础图、17 个复合模板的数据区、逐对相关、类型纠正、缺失值、小样本 / 常量密度、直方图计数、SVG mm / viewBox，以及 PNG DPI 双轴与 CRC。
- TypeScript、目标文件 ESLint、Next 生产构建检查。
- 窄屏验证：390 px 宽度无页面横向溢出，基础图完整缩放预览。主曲线新增导出区后发现原吸顶预览遮挡设置与按钮，改为正常文档布局；提高默认刻度 / 图例字号，85 mm 下检查无小于 6pt 提示。论文导出来源脚注也由 7 / 8 px 提高到 12 px，默认 180 mm 下可读。
- 浏览器上传自编 10 行 CSV：其中一行缺失、一行无效数值。箱线图保留 8 个真实观测，A 组 n=6、B 组 n=2；原始零值保留，不补零。
- 浏览器真实 PNG 下载：85 mm / 300 DPI 输出 1004×620 px，读出 DPI 299.9994；600 DPI 输出 2008×1240 px，读出 DPI 599.9988。像素舍入及 PNG 每米整数导致小数偏差，不代表尺寸设置失效。
- 灰度 PNG 的所有像素 R=G=B；SVG 根元素为 85 mm × 52.5 mm，保留 viewBox。
- PDF 只确认浏览器打印预览为一页；未验证最终保存 PDF 的页尺寸和全部路径矢量性，需按界面提示关闭页眉页脚、100% 打印。

上述检查只针对明确列出的行为，不是期刊合规或统计结论认证。
