## 当前取舍

数值图按用户自己的系列、类别与范围重新绘制，无需准备原论文数量的 a–h 面板。同一结构因论文名称、指标和配色不同产生的卡片合并；分组柱状与误差、数值 X 折线与分类时间趋势、绝对堆叠与百分比、曲面与向量等实际结构差异仍保留。纹理和单位参考球可在编辑器切换；XYZ散点与原点向量分别提供不同几何预设。密度、注意力、频率热图，以及两层分组箱线、局部范围雷达和分段配对曲线独立保留。

论文代表保留来源和参考配色，演示值独立编写，不是论文实验数据；不会把原论文的 P 值、公式或结论套用在新数据上。当前目标是可替换表格的科研数据图，不承诺复刻整张论文版式或编辑原插图内部路径。

新增电化学模板复用折线与双轴引擎，但按实验用途提供不同坐标、表头建议与校验。Nyquist 上传后要求显式确认 Im(Z) / −Im(Z)，不用绝对值，并保持同单位轴的像素长度一致；Bode 的原始频率与模值须大于零，相位保留符号；循环性能右轴 CE 可以关闭。上传后使用实际表头，不自动换算单位、参比、面积或质量，也不拟合电化学参数。新增模板和演示表独立编写，没有引入外部实验图或图片许可。

## 历史版本对原图保真方式的判断

仅把具体论文图压缩成三类通用模板会产生明显差距，已改为逐张复合模板。当前保留原图的版面、框架、原始标注，并允许替换数据模块与文字；复杂蛋白结构 / 网络等提供整模块图片替换。不能把这种实现称为「原图内部每条路径均可编辑」。如果要达到全矢量编辑，需为每张图逐个重建结构和路径，当前未完成。

未替换数值区仍是原作者数据。新数据不会重算原来的 P 值、公式、结论，检查界面明确列出这些提示。原图 CC BY-NC 4.0 与 SciPilot MIT 分开保留，MIT 不覆盖论文图片。
