# 同一软件的多系统下载

软件插件目录将显式采用 `产品名称 · Windows 版`、`产品名称 · Mac 版（Apple Silicon）` 或 `产品名称 · macOS 版` 的已发布条目组合成一张产品卡片。适用软件分类必须一致；普通条目、相似名称和不同分类不会合并。平台安装包继续使用各自的原始记录、权限和下载接口，产品目录数量按组合后的产品计算。

Fesilent Mouse 现有两个版本因此共享一个详情。共同功能只显示一次；系统按钮切换对应的运行环境和安装说明。点击“下载安装包”进入版本选择，默认不选中任何版本，用户选择 Windows x64 或 Mac Apple Silicon 后才能确认下载。选择项显示芯片要求、版本、大小及确认后的文件名。

任一旧 `?plugin=<安装包 ID>` 链接均打开统一产品详情，并定位原平台的安装说明。登录返回链接额外保留 `download=<安装包 ID>`，返回时恢复选择，不自动开始下载。取消、返回产品或关闭详情会取消尚未完成的下载；重新选择版本会清除上一次的进度和错误。

管理员可在统一详情切换系统后编辑该平台介绍、下架或更新安装包。命名中的产品部分需保持一致，平台后缀用于识别系统；下架的版本不会出现在选择列表中。

验证：平台组合、旧链接、文件映射、隐藏版本缺席、搜索与版本差异由 `products.test.mjs` 覆盖；原下载校验与权限测试继续运行。
