# Single-panel assets

Original figures: Chen Liu and collaborators, figures4papers.
Source: https://github.com/ChenLiu-1996/figures4papers
License: CC BY-NC 4.0, retained in ../paper-figures/LICENSE.txt.

These previews and illustration backplates were cropped from the 17 figure backplates already attributed in ../paper-figures/ATTRIBUTION.md, using region coordinates in src/lib/data-processing/paper-figures/catalog.ts. Previews were resized and padded with white space. No original paper data, conclusions or scientific labels were recomputed. Each file name includes the source figure ID and the selected region ID.

Numerical editors render new standalone vector charts from user-supplied data; preview crops are style references and are not embedded in those numerical exports. Illustration exports embed the selected single-module backplate, or its user-supplied replacement.
