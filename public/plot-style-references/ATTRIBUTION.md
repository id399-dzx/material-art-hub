Reference: [liouhai/plot-is-all-you-need](https://github.com/liouhai/plot-is-all-you-need), MIT, Copyright (c) 2026 qc. See [LICENSE.txt](LICENSE.txt).

Fesilent Reverie uses selected color values from the repository's original Matplotlib examples to assemble new categorical and numeric palettes. Its comparison workflow is inspired by the repository's same-data variants and separate design choices. The React/ECharts picker, chart engines, thumbnails and comparison interface are independently implemented for the website.

No gallery publication images, experimental datasets, Python scripts, external skill instructions or third-party paper artwork are redistributed here. Original paper-style template attribution remains in ../paper-figures/ATTRIBUTION.md.
